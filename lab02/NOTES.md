git status - отображает текущее состояние рабочей директории и индекса
git diff  сравнивает файлы в рабочей директории с индексом
git diff --staged - показывает изменения, которые уже добавлены в индекс и попадут в следующий коммит


Ветка (Branch) — это указатель на один из коммитов, представляющий собой независимую линию разработки. Она позволяет изолированно работать над новыми фичами или исправлениями, не влияя на основной код.
При новом коммите текущаяактивная ветка автоматически сдвигается вперед, указывая на этот самый свежий коммит,получается история ветки растет с каждым новым сохранением
Слияние — это процесс объединения изменений из одной ветки в другую. При слиянии Git берет историю целевой ветки и переносит в неё наработки из исходной
